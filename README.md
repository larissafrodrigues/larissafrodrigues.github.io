# Larissa F. Rodrigues Moreira — Academic Website

Static bilingual (EN/PT-BR) academic website prepared for GitHub Pages.

## Visual direction
- modern sans-serif typography (Manrope with system fallback)
- warm neutral + wine/berry palette inspired by the portrait
- photo-forward homepage using the supplied professional portrait
- clean academic cards and restrained shadows
- contact page intentionally keeps the simple icon + location + map spirit of the previous website

## Structure
- `index.html` — photo-forward homepage
- `about.html` — bio, education, honors, Full CV link
- `research.html` — research themes + prominent NextAI research-group link
- `students.html` — mentorship
- `teaching.html` — courses
- `publications.html` — searchable/filterable publication list
- `contact.html` — email, institutional location, map, academic profiles, Full CV
- `assets/` — CSS, JavaScript, portrait, and CV

## Key external link
- NextAI Research Group: https://nextai.ufv.br/

## Publishing
Copy the contents of this folder to the root of `larissafrodrigues.github.io` and push to the GitHub Pages branch. No build step is required.

## Language
English is the default. The EN/PT switch is stored locally in the browser. URLs can also use `?lang=en` or `?lang=pt`.
